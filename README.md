# Editor Claude

Skills para editar tus videos con Claude, en español sencillo y sin saber de tecnología.

## Cómo instalarlo (una sola vez)
1. En la app de Claude ve a **Personalizar → Plugins → Agregar → Agregar marketplace**.
2. Pega la dirección de este repositorio (`jennmahecha-create/editor-claude`) y deja encendido **Sincronizar automáticamente**.
3. Busca **editor-claude** en Plugins y toca **Agregar**.

Se actualiza solo cada vez que mejoramos algo.

## Qué incluye
- **EditorPRO**: revisa tu computador, instala con permiso lo que falta (Mac Intel, Mac Apple Silicon o Windows) y crea tu carpeta «Mis videos».

En una conversación nueva de Claude (pestaña **Code**), escribe solo: **EditorPRO**

## En Claude Code
```
/plugin marketplace add jennmahecha-create/editor-claude
/plugin install editor-claude@editor-claude
```
